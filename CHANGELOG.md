\# Changelog



All notable changes to the Modular Arrangement System are listed here.



\## \[1.0.1] - 2026-10-22



\### Added

\- Example project (Temple scene) with ready-made arrangement presets.

&#x20; Download: \[MAS\_Example.zip](https://github.com/Purryte/UE5-ModularArrangementSystem/raw/main/examples/MAS\_Example.zip)

&#x20; Requires UE 5.1+ and the Modular Arrangement System plugin.



\### Changed

\- Filters can now keep a single item. Modifiers below the filter apply to that one actor,

&#x20; e.g. filter `Cube\_10` out of 100 cubes and give only it a Location Offset.

&#x20; A warning now appears only when a filter keeps no items.



\### Fixed

\- Duplicate modifier with shortcut(Ctrl+C / Ctrl+V) in the editor cause conflicts with copy/paste actors operations.


\## \[1.0.0] - 2026-10-19



\- Initial release.
